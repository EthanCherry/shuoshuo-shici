## 二、你的作品是什么（一句话）

给粤语 / 英语学习者用的网页双语口语搭子：把你想说的话整理成地道英语或粤语口语，边聊边攒生词，并且**记住你今天聊过什么、能回溯前几天聊过什么**。

## 三、为什么做

- 真实痛点 1：中英夹杂、粤语口语不敢开口——现有工具要么只认标准英语，要么直接替你说错话。
- 真实痛点 2：AI 聊完就忘，第二天接不上，练习没有连续性。
- 真实痛点 3：对话里遇到的好词散落在聊天记录里，攒不下来、复习不到。
- 想法来源：把自己两个割裂的原型（说说英语 / 拾词）融合，并加上一层"会记忆"的对话系统，让口语练习变成可持续积累的习惯。粤语全程靠 prompt 工程实现，不做数据集训练、不人工录音。

## 四、怎么用（5 步，评委照着能自己打开用起来）

1. 打开作品链接（免登录、无需密钥；公网为"演示模式"，预置语料保证开箱即用）。
2. 点输入框上方示例（如"感冒了""上班累(粤)"），或长按粤语 / 英语按钮说话、直接打字（中英夹杂也可以）。
3. 点「整理表达」，核对 AI 整理出的英语 / 粤语（粤语附粤拼），勾选确认后发送。
4. 看搭子回复与生词 chips，点「＋」收藏整句或生词；切到「复习 / 查词 / 语料库」看积累闭环。
5. 进「设置 → 对话记忆与用户画像」：看今天全量轮数、已压缩天数、画像 md；可刷新画像、导出记忆 JSON。

## 五、用 Qoder 做出来的过程（哪几步交给它、我改了什么）

交给 Qoder 的（附截图凭证，见文末清单）：
1. 融合方案与双语路线调研：确认粤语可用 prompt 工程实现，无需训练 / 录音；规划局域网优先、成熟后上云。
2. 统一后端：Node 原生 http + DeepSeek 代理（`thinking: disabled`、`response_format: json_object`、限流、输出校验），密钥只留服务端。
3. 界面重设计：先调研简约风格，再落地"灰石"设计系统；把我给的色卡采样后替换所有偏黑组件为沙色。
4. 分层记忆：调研 MemGPT / Letta 后实现 `memory.mjs`——今日全量优先注入、跨天自动压缩、过去指代回溯、谈吐画像；26 项 node:test 全过。
5. 参赛调研与部署：核对赛制 / 提交规范 / 各赛道作品后选定 StudyHack；实现无 key 离线演示引擎 `demo.mjs` 与自动降级；注册 Sites workbench（`--site-*` 设计变量）、prepare / publish、设公开访问；公网控制台 0 报错。
6. 开源交付：gh 设备登录、创建 public 仓库、补 README 与 `.env.example`，确认密钥 / 记忆 / 原件不入库。

我改 / 我决定的：
- 首屏必须是对话练习；语种检测改为两个长按按钮（粤语 / 容忍中英夹杂的英语）。
- 审美方向选"灰石"，又用色卡把偏黑组件换成沙色；发音评分先留占位不造假。
- 记忆的四层要求（今天牢牢记住 / 逐天压缩 / 提到过去就回溯 / 谈吐画像）由我提出并验收。
- 参赛选 StudyHack；授权站点公开与仓库开源；文案口径（如"整理表达"而非"开始模拟面试"式卖课腔）由我把关。

## 二、作品是什么

把你不敢开口的话，整理成地道英语 / 粤语；边聊边攒词；还记得你们聊过什么。

## 三、为什么做

三个痛点：

1. 中英夹杂、粤语口语——现有工具不认。
2. AI 聊完就忘——练习接不上。
3. 好词散在聊天记录里——攒不下、复习不到。

做法：融合两个原型，加一层会记忆的对话。粤语靠 prompt 工程，不训练、不录音。
错句闭环：你的蹩脚原句自动入册，变成复习考题和"中式习惯"档案——改一次，记住习惯，反复考。

## 四、怎么用（5 步）

1. 打开链接。免登录、免密钥。
2. 点示例，或长按说话 / 打字（中英夹杂也行）。
3. 「整理表达」→ 核对（粤语带粤拼）→ 勾选发送。
4. 看回复，点「＋」攒词；复习（含错句回放）/ 查词 / 语料库成闭环。
5. 设置 → 记忆面板：今天聊了什么、前几天聊了什么、你的画像。

## 五、Qoder 做了什么 / 我做了什么

Qoder：

1. 调研：粤语 prompt 可行性、赛制、各赛道作品。
2. 后端：Node + DeepSeek 代理，限流、校验；密钥只留服务端。
3. 界面：简约风 →「灰石」→ 按我的色卡换沙色。

5. 部署：无 key 演示引擎 + Sites 发布公开；控制台 0 报错。
6. 开源：public 仓库 + README；密钥不入库。
